# Linux course notes (Tel-Ran, 2022)

[English](README.md) | [Русский](README.ru.md)

Linux lesson notes and reference guides from the Tel-Ran course for groups 31/32e. The lessons cover command-line tools, text editing, SSH, Git, shell scripts, scheduling and archives. The lesson notes are in Russian.

## Structure

```text
lessons/       # Notes grouped by topic, in DOCX and Pages formats
references/    # PDF guides and command cheat sheets
```

## Lessons

| Topic | Notes |
| --- | --- |
| Files, directories and basic commands | [Basic commands](lessons/basic-commands.docx) |
| Pipes, redirection and writing to files | [Pipes and redirection](lessons/pipes-and-redirection.docx) |
| Text editors and an introduction to SSH | [DOCX](lessons/text-editors-and-ssh.docx), [Pages](lessons/text-editors-and-ssh.pages) |
| SSH keys and remote access | [SSH keys](lessons/ssh-keys.docx) |
| Git and GitHub basics | [Git basics](lessons/git-basics.docx) |
| Shell scripts and file permissions | [Scripts and permissions](lessons/shell-scripts-and-permissions.docx) |
| Scheduled tasks and tar archives | [Cron and archives](lessons/cron-and-archives.docx) |

## Read locally

```bash
git clone https://github.com/ivan-zamula/linux-course-notes-2022-tel-ran.git
cd linux-course-notes-2022-tel-ran
```

Open DOCX files in Microsoft Word or LibreOffice Writer, Pages files in Apple Pages, and PDF guides in a PDF reader.

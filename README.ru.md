# Материалы курса Linux (Tel-Ran, 2022)

[English](README.md) | [Русский](README.ru.md)

Материалы занятий и справочники курса Linux в Tel-Ran для групп 31/32e. Темы: команды терминала, работа с текстом, SSH, Git, shell-скрипты, планирование задач и архивы. Конспекты занятий написаны на русском языке.

## Структура

```text
lessons/       # Материалы по темам в форматах DOCX и Pages
references/    # Справочники PDF и шпаргалки по командам
```

## Чтение на компьютере

```bash
git clone https://github.com/ivan-zamula/linux-course-notes-2022-tel-ran.git
cd linux-course-notes-2022-tel-ran
```

Открывайте DOCX в Microsoft Word или LibreOffice Writer, Pages — в Apple Pages, справочники PDF — в программе для чтения PDF.
